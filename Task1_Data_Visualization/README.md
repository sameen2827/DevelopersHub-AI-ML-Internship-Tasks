# Task 1: Exploring and Visualizing the Iris Dataset

## Objective
The objective of this task is to explore and visualize the Iris dataset using Python libraries such as Pandas, Seaborn, and Matplotlib.

## Dataset Used
Features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species
Total Samples: 150

## Libraries Used
- Pandas
- Seaborn
- Matplotlib
- Jupyter Notebook

### Data Inspection
- Loaded dataset
- Checked dataset shape
- Displayed column names
- Viewed first five rows
- Generated dataset information
- Generated statistical summary

### Data Visualization
- Scatter Plot
- Histogram
- Box Plot

## Key Findings
- Petal Length and Petal Width have a strong positive relationship.
- Species are clearly distinguishable in scatter plots.
- Histograms reveal feature distributions.
- Box plots help identify outliers and data spread.

## Results
The dataset was successfully explored and visualized. Exploratory Data Analysis (EDA) provided insights into feature relationships and distributions, forming a foundation for future machine learning tasks.
