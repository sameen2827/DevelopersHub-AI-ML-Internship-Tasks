# Task 6: House Price Prediction

## Objective

. Predict house prices using property features.
. Build and evaluate a regression model.

## Dataset

 House Price Prediction Dataset (Kaggle)
 Features:

  Area/Square Footage
   Bedrooms
   Bathrooms
   Location and other house attributes
Target: House Price

## Tools & Libraries

. Python
. Pandas
. NumPy
. Matplotlib
. Scikit-learn

## Workflow

. Load and preprocess the dataset.
. Select features and target variable.
. Split data into training and testing sets..
. Train a Linear Regression model.
. Predict house prices.
. Evaluate using MAE and RMSE.
. Visualize Actual vs Predicted Prices.

## Skills Learned

 Data Preprocessing
 Regression Modeling
 Model Evaluation
 Data Visualization

## Conclusion

A Linear Regression model was used to predict house prices based on housing features and evaluated using MAE and RMSE metrics.
